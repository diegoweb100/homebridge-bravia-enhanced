The TV issues a pairing cookie valid 14 days. The plugin renews it on its own while the TV is on (once a day), so you should never need a new PIN.

Pair with the TV

One-time step: the TV shows a 4-digit PIN, you type it here. The plugin then keeps a pairing cookie and reconnects on its own.

1
Switch the TV onIt must be on, not in standby, to show the PIN.
2
Show the PINPress the button below: a PIN appears on the TV.
3
Type the PINEnter the 4 digits and confirm.

No PIN on screen? Make sure the TV is on and try again. On Bravia XR models you may need a Pre-Shared Key instead (psk in the plugin settings).

Reset pairing

Deletes the stored cookie so the plugin pairs again. Use it only if the TV stopped responding. To force a brand new PIN also remove “homebridge” from the TV menu Network → Remote device settings → Registered devices.
